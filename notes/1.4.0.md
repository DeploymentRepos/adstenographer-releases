# 1.4.0

Stenographer is in beta. These are the changes since 1.3.0.

- **Fewer Keychain password prompts.** Stenographer no longer asks for your
  password once per saved item after an update.
- **Events that can't be read show up in Ingestion Errors.** A malformed event
  file now lands in the list the Ingestion Errors window shows, instead of a
  directory nothing looked at.
- **AI provider settings stay intact.** Sending your AI provider settings to the
  daemon now reports anything it could not apply, and never removes settings
  another app saved.
- **Session summaries wait long enough.** A summary request now waits the full
  "Give up after" time you set, and large session reads get more time before
  they are abandoned.
- **Starting the daemon can't hang.** Starting the background service from the
  app has a 30-second time limit again.
- **`steno hook --help` answers immediately.** It, and a missing `--event`, no
  longer wait for input first.
- **Tool results that carry their own id are recorded.** An event such as a
  scheduled task's result could fail to record and stay in Ingestion Errors
  however often it was retried. It now records, and retrying an event already
  stuck there clears it.
- **Behind the scenes.** Much of the session-tracking code moved into libraries
  Stenographer shares with Agentic Developer Kitchen. Nothing should look
  different. Report anything that does.
