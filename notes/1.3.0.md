# 1.3.0

Stenographer is in beta. These are the changes since 1.2.0.

- **Account router (off by default).** Stenographer can now sit between Claude
  Code and Anthropic on `localhost:22848` and spread requests across your saved
  Claude accounts, moving off an account that hits its rate limit. Turn it on
  in Settings or with `steno router enable`. `steno router report` and
  `steno router log` show what it did. While the router is on, stopping
  Stenographer points Claude Code straight back at Anthropic until Stenographer
  starts again. This is new and has had limited real-world use.
- **Claude model router with templates.** With the router on, a template can
  pick which Claude model handles each kind of request — for example, a
  cheaper model for side requests. Templates are edited in their own dialog,
  and the routing log window shows each request and the rule that routed it.
  The router uses the same proxy and certificate settings Claude Code does;
  this has not been tried behind a corporate proxy.
- **Accounts in Settings.** A new **Accounts** pane signs you in to the
  Agentic Developer Hub through the hub's own web page. It is a first sign-in
  path, not a finished account system.
- **Account switching no longer freezes.** A switch that got stuck waiting on
  a credential check could hang the quotas window. Every wait now has a time
  limit.
- **Quota sections stay after a quota week ends.** Accounts whose weekly quota
  window had lapsed could drop out of the usage display; they now stay.
